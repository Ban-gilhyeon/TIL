# 자릿수 처리

## 마지막 자리 추출과 제거

작성일: 2026-10-01

10진수 정수의 끝자리부터 처리할 때 `% 10`으로 마지막 자리를 꺼내고 `/= 10`으로 제거한다.

```java
long num = n;
List<Integer> digits = new ArrayList<>();

while (num > 0) {
    int digit = (int) (num % 10);
    digits.add(digit);
    num /= 10;
}
```

`12345`는 `5 → 4 → 3 → 2 → 1` 순서로 나온다. 반복문 안의 `num /= 10`을 빼먹으면 무한 반복한다.
