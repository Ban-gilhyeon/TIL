# 연속 중복 제거

## 마지막 결과값과 현재 값 비교

작성일: 2026-10-01

연속 중복만 제거하고 원래 순서를 유지할 때는 결과에 마지막으로 남긴 값만 비교한다.

```java
Deque<Integer> result = new ArrayDeque<>();

for (int value : arr) {
    if (result.isEmpty() || result.peekLast() != value) {
        result.addLast(value);
    }
}

return result.stream()
        .mapToInt(Integer::intValue)
        .toArray();
```

예: `[1, 1, 3, 3, 0, 1, 1]` → `[1, 3, 0, 1]`

중요: 전체 배열에 이미 등장했는지가 아니라 **바로 직전 결과값**만 비교한다. 따라서 `1, 3, 1`의 마지막 `1`은 남긴다.

- 시간: `O(n)`
- 추가 공간: `O(n)`
