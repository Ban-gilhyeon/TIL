# 컬렉션

## List, Map, Deque와 ArrayDeque

작성일: 2026-10-01

코테에서는 자료구조가 맡은 역할에 맞는 인터페이스 타입으로 선언하고, 적절한 구현체를 생성한다.

```java
List<Integer> list = new ArrayList<>();
Map<Integer, Integer> count = new HashMap<>();
Deque<Integer> deque = new ArrayDeque<>();
```

### `List`

인덱스 순서가 있는 값 모음. 빈 `ArrayList`는 없는 인덱스에 대입할 수 없다.

```java
List<Integer> values = new ArrayList<>();
values.add(3);       // 추가
values.set(0, 10);   // 이미 존재하는 0번 값 교체
```

### `Map`

키별 개수 세기.

```java
Map<Integer, Integer> count = new HashMap<>();

for (int size : tangerine) {
    count.put(size, count.getOrDefault(size, 0) + 1);
}
```

### `Deque`

양쪽 끝에서 넣고 뺄 수 있는 인터페이스. 스택과 큐 모두 구현 가능하다.

```java
Deque<Integer> result = new ArrayDeque<>();

result.addLast(1);  // 뒤에 추가
result.peekLast();  // 뒤 값 확인
result.removeLast();
```

`Stack`은 오래된 클래스라 코테에서는 보통 `Deque<Integer> stack = new ArrayDeque<>();`를 사용한다.

### 인터페이스 타입으로 선언하는 이유

```java
Deque<Integer> deque = new ArrayDeque<>();
```

- 변수 타입은 `Deque` 인터페이스, 실제 객체는 `ArrayDeque` 구현체.
- 이는 업캐스팅이다. 다운캐스팅이 아니다.
- 나중에 `new LinkedList<>()`로 구현체를 바꿔도 `Deque` 공통 메서드를 쓰는 코드는 유지된다.
- `ArrayDeque` 고유 기능이 꼭 필요할 때만 변수 타입도 `ArrayDeque`로 선언한다.
