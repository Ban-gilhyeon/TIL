# 스트림

## `mapToInt`와 메서드 참조 `::`

작성일: 2026-10-01

`Stream<Integer>`를 원시 타입 `int` 스트림으로 바꾸려면 `mapToInt`를 사용한다.

```java
return result.stream()
        .mapToInt(Integer::intValue)
        .toArray();
```

`Integer::intValue`는 메서드 참조다. 아래 람다와 같다.

```java
.mapToInt(x -> x.intValue())
```

`intValue()`는 `Integer` 객체가 가진 메서드이며 `int`는 타입 이름이라 `Integer::int`는 존재하지 않는다.

자주 보는 메서드 참조:

```java
Integer::parseInt // static 메서드
String::length    // 각 String의 length() 호출
Integer::intValue // 각 Integer의 intValue() 호출
ArrayList::new    // 생성자 참조
```

`Integer`는 래퍼 타입, `int`는 원시 타입이다. `mapToInt`는 원시 타입 `int`를 반환하는 함수를 요구한다.
