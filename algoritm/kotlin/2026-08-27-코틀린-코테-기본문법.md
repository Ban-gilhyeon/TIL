# Kotlin 코테 기본 문법

## 숫자 타입과 변환

Kotlin은 `Int`, `Long`, `Double`을 구분한다.

```kotlin
val n: Long = 123L
val intValue = n.toInt()
val doubleValue = n.toDouble()
```

- `Long`으로 계산한 자릿수는 `Long`이다. `IntArray`나 `MutableList<Int>`에 넣을 때 `toInt()` 한다.
- 숫자 문자열 변환: `s.toInt()`, `s.toLong()`.
- 숫자가 아닐 가능성이 있으면 `s.toIntOrNull()`, `s.toLongOrNull()` 사용. 실패 시 `null`.

## 배열과 리스트

```kotlin
val arr = intArrayOf(1, 2, 3) // IntArray
arr.size                       // 배열/리스트 원소 수

val list = mutableListOf<Int>()
list.add(3)                    // 맨 뒤에 추가
val result: IntArray = list.toIntArray()
```

- `intArrayOf()`는 크기 0인 고정 배열. `answer[0] = x`, `answer.add(x)` 불가.
- 크기를 모르면 `mutableListOf<Int>()`에 `add()` 후 `toIntArray()`.
- `map { it.toInt() }` 결과는 읽기 전용 `List`. 원본 변경 `sort()`를 쓰려면 `toMutableList()` 필요.
- 새 정렬 리스트가 필요하면 `sorted()`, 원본 `MutableList` 정렬은 `sort()`.

```kotlin
val sorted = s.split(" ").map { it.toInt() }.sorted()

val mutable = s.split(" ").map { it.toInt() }.toMutableList()
mutable.sort()
```

## 반복과 인덱스

```kotlin
for (value in arr) {
    // value는 원소 값. 인덱스 아님.
}

for (index in arr.indices) {
    // arr[index] 가능
}
```

`for (i in arr)`에서 `i`는 원소다. `arr[i]`는 `i`가 `Long`이면 인덱스는 `Int`여야 해서 오류 난다.

## 문자열과 문자

```kotlin
val numbers = s.split(" ").map { it.toInt() }

c.isDigit()        // 숫자 판별
c.isLetter()       // 알파벳 판별
c.uppercaseChar()  // 대문자 변환
c.lowercaseChar()  // 소문자 변환
```

- `split(" ")` 결과는 `List<String>`이다. 리스트 전체가 아니라 각 문자열에 `toInt()` 적용.
- `'3'.digitToInt()`는 한 글자 숫자 변환용. `"-1"` 같은 숫자는 `String.toInt()` 사용.
- 문자열 처리 중 상태를 기억할 때 Boolean 사용:

```kotlin
var isFirst = true
```

공백이면 `isFirst = true`, 공백 아닌 글자 처리 후 `isFirst = false`.

## 실수 함수와 제곱

```kotlin
import kotlin.math.*

val root = sqrt(n.toDouble())        // Double 반환
val squared = x.toDouble().pow(2)    // Double에서 pow 사용
```

- `sqrt()`와 `pow()`는 `Double`/`Float` 기반.
- 정수 제곱은 실수 `pow()`보다 곱셈이 더 안전하고 간단하다.

```kotlin
val squared = x * x
```

## 평균에서 정수 나눗셈 피하기

```kotlin
return total.toDouble() / arr.size
```

한쪽만 `Double`로 만들면 결과도 `Double`. `var answer = 0`은 `Int`로 추론되므로 `Double`을 넣으려면 `0.0`으로 시작해야 한다.
