# 기초 수학·문자열 풀이 패턴

## 약수의 합

제한이 작으면 `1..n`을 순회하며 나누어떨어지는 수를 더한다.

```kotlin
var sum = 0
for (i in 1..n) {
    if (n % i == 0) sum += i
}
```

큰 입력에서는 약수가 짝으로 나온다는 점을 이용해 `sqrt(n)`까지만 검사할 수 있다.

## 자릿수 꺼내기

끝자리 추출과 제거:

```kotlin
val digit = num % 10
num /= 10
```

```kotlin
while (num > 0) {
    val digit = num % 10
    // digit 사용
    num /= 10
}
```

- `12345`에서 꺼내는 순서: `5, 4, 3, 2, 1`.
- 뒤집은 자릿수 배열을 만들 때는 그대로 리스트 끝에 `add()`하면 된다.
- `while` 내부 `num /= 10`을 빼먹으면 무한 루프.

## 자릿수로 새 숫자 만들기

내림차순으로 정렬한 자릿수 `[8, 7, 3]`을 정수 `873`으로 만들기:

```kotlin
var answer = 0L
for (digit in arr) {
    answer = answer * 10 + digit
}
```

자리수와 `10의 거듭제곱`을 따로 관리하는 것보다 짧고 실수 적다.

## 완전제곱수 판별

제곱근을 정수로 잘라 다시 제곱해 원본과 비교한다.

```kotlin
val x = sqrt(n.toDouble()).toLong()

if (x * x == n) {
    return (x + 1) * (x + 1)
}
return -1
```

`sqrt(n) % 1.0 == 0.0` 방식보다 정수 재제곱 비교가 코테에서 안전하다.

## 하샤드 수

1. 자릿수 합 `total` 계산.
2. 원본이 `total`로 나누어떨어지는지 검사.

```kotlin
return x % total == 0
```

`if (조건) true else false`처럼 Boolean 결과를 만들기보다 조건식을 바로 반환할 수 있다.

## 최솟값·최댓값

공백 문자열을 숫자 리스트로 바꾸기:

```kotlin
val arr = s.split(" ").map { it.toInt() }
```

최솟값과 최댓값만 필요하면 정렬 없이:

```kotlin
"${arr.minOrNull()} ${arr.maxOrNull()}"
```

정렬 연습 풀이:

```kotlin
val sorted = s.split(" ").map { it.toInt() }.sorted()
"${sorted.first()} ${sorted.last()}"
```

## 문자열 단어 첫 글자 처리

문자 하나씩 순회하며 `isFirst` 상태로 단어의 시작을 기억한다.

```kotlin
var isFirst = true

for (c in s) {
    if (c == ' ') {
        isFirst = true
    } else {
        // 첫 글자면 대문자, 나머지는 소문자
        isFirst = false
    }
}
```

연속 공백이 가능하면 `split` 후 재조합보다 이 방식이 공백을 그대로 보존하기 쉽다.
